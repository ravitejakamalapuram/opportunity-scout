# Opportunity Scout

A living, evidence-first portfolio of software-business opportunities for a solo senior developer.

## Goal

Find real problems → validate cheaply → build small → launch → monetize → automate → maintain or kill.

The repository is intentionally **not** an idea dump. It is a decision system.

## Opportunity lifecycle

```
NEW → VALIDATING → BUILD → LAUNCH → GROW → MAINTAIN
  \____________________ KILL _____________________/
```

## Core rule

Evidence beats imagination.

Every opportunity should eventually answer:

1. Who has the problem?
2. Who pays?
3. What do they do today?
4. Why is that inadequate?
5. What evidence proves the pain?
6. Why now?
7. What is the smallest useful product?
8. How cheaply can we validate it?
9. What would make us kill it?

## Repository conventions

- `INDEX.md` = current portfolio dashboard.
- `ideas/*.md` = durable opportunity dossiers.
- `daily/*.md` = dated research snapshots.
- `DECISIONS.md` = important decisions and reversals.
- `PIPELINE.md` = lifecycle and active experiments.
- Never delete killed ideas; preserve their history.
